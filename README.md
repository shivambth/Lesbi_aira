# For Aira ❤️ - 4-Month Anniversary Love Story Website

A premium, deeply emotional, interactive digital love book created by Shivam for Aira to celebrate their 4-month anniversary (6 July 2026).

## Features
- **Realistic Book Layout & 3D Feel**: Dark chocolate-brown and champagne-gold luxury theme with cover opening and page controls.
- **Natural Indonesian Language & Instant English Translation**: Toggle button (`🌐 EN / ID`) to instantly switch the entire book between Indonesian and English.
- **Rich Mixed Content**: Paragraphs interspersed with cute GIFs, stickers, and 50 scrapbook photo frames using existing photos in `assets/photos/`.
- **50 Reasons Why I Adore You**: Detailed reasons with an "unlimited books" note.
- **9 Playable Mini-Games**: Fully interactive quizzes, memory match, emoji decode, word scramble, hidden heart finder, and more.
- **Deep Emotional Letters**: 10+ heartfelt chapters covering Litmatch, WhatsApp, first 10 days, misunderstandings, first call, bad moods, future meeting next year, and nicknames (Bebyycuu, Cantikkcuu, Duniyakuu, Darlingcuuu, Istriicuuuu, Gay, Lesbian).
- **Special Final Surprise**: Highlighting **LESBICUUUU ❤️**.

## How to Run
1. Unzip the archive.
2. Ensure your 50 photos are placed inside `assets/photos/` with their exact filenames.
3. Open `index.html` in any web browser or deploy directly to GitHub Pages.
